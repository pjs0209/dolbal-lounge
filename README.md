# 돌밭 라운지 · DOLBAT

기계공학과와 전자전기공학과의 돌밭 재학생·졸업생이 한곳에서 질문과 경험을 나누는 부원 게시판입니다. 홈페이지 주소는 누구나 열 수 있습니다. 질문, 사진, 답변, 선배 목록은 운영진이 확인한 부원에게만 공개합니다.

## GitHub에 올리기

1. GitHub에서 공개 저장소를 만듭니다. 예시 이름은 `dolbat-lounge`입니다.
2. 이 파일과 `docs`, `setup` 폴더를 저장소의 첫 화면에 업로드하고 main 브랜치에 저장합니다. 압축 파일 자체를 올리면 사이트가 열리지 않습니다.
3. 저장소 **Settings → Pages**에서 **Deploy from a branch**를 고르고 **main /docs**를 선택한 뒤 저장합니다.
4. 배포가 끝나면 같은 화면의 **Visit site**에서 공개 주소를 확인합니다. 저장소 소유자만 GitHub를 사용합니다.

## 실제 사용

`docs/config.js`에는 돌밭 전용 서버의 공개 접속 설정이 들어 있습니다. 운영 데이터베이스와 가입 기능은 이미 준비돼 있습니다. 서버 관리자 키나 비밀번호는 저장소에 넣지 않습니다.

처음 방문한 부원은 **부원 로그인 → 처음 방문하셨나요? 부원 가입**에서 돌밭 아이디와 비밀번호를 만들고, 확인용 이름, 게시판 닉네임, 재학·졸업 구분과 소속 학과를 입력합니다. 선배 찾기에서는 부원들이 같은 명단을 보고 닉네임이나 소개로 선배를 찾을 수 있습니다. 졸업생은 선배 찾기에 프로필을 표시할지 선택할 수 있습니다. 별도의 GitHub 계정이나 이메일 인증은 필요하지 않습니다.

### 운영진의 부원 승인

운영자는 [회원 관리 화면](https://supabase.com/dashboard/project/wpguhpvljckqoammlyvj/editor)에서 `dolbal_profiles`를 선택합니다. `approved = false`인 신청자의 `member_name`과 구분을 동아리 명단으로 확인한 후 해당 행의 `approved`를 true로 저장합니다. 승인 취소는 false로 되돌립니다. 가입자는 **내 가입 상태 → 상태 새로고침**을 누릅니다. 실명 확인용 값은 일반 회원의 API 조회에서 제외됩니다.

### 질문과 사진

승인된 재학생과 졸업생 모두 질문하고 답변할 수 있습니다. 질문과 답변을 작성할 때 전공, 입학연도, 이름을 입력합니다. 입학연도는 22 또는 2022로 입력하면 22학번으로 표시됩니다. 세 항목은 승인된 부원이 글을 볼 때 함께 표시됩니다. 질문·답변마다 사진 한 장을 첨부할 수 있고, 사진은 브라우저에서 크기를 줄여 글과 함께 저장합니다. 선배를 지정한 질문도 부원 전체가 볼 수 있습니다. 질문 제목, 내용, 답변으로 과거 경험을 찾을 수 있습니다.

## 구성

- `docs/`에는 정적 사이트가 있습니다. 빌드나 패키지 설치가 필요하지 않습니다.
- `setup/schema.sql`은 빈 Supabase 프로젝트를 위한 초기 스키마 원본입니다. 현재 돌밭 프로젝트에는 이미 적용했습니다.
- `setup/dolbal-enroll/index.ts`는 전용 아이디의 계정을 만드는 서버 함수입니다. 요청은 플랫폼의 서명된 공개 게이트웨이 키로 검증합니다. 관리자 키는 서버 기본 환경에서만 읽습니다. 계정이 생긴 뒤에도 부원 승인이 필요합니다.
- 로컬에서 가상 부원으로 시험하려면 별도 복사본에서 `config.js`의 `mode`를 `demo`로 바꾸고 정적 웹 서버로 엽니다. 예시 데이터와 체험 기록은 운영 데이터베이스에 저장되지 않습니다.
